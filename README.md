# Java Fundamentals (16-week Program)

This repository contains my Java console assignments completed during a 16-week UNITWIN Java Fundamentals program (Sep 2025 – Jan 2026).

## Topics covered
- Variables and data types
- Conditional statements
- Loops
- Methods / functions
- Arrays
- Basic Object-Oriented Programming (OOP)
- Debugging and problem-solving practice

## Structure
Assignments are organized by week in the `assignments/` folder. Each program can be run using any Java IDE or from the command line.

## Notes
These are beginner practice programs intended to demonstrate foundational programming skills and consistent learning progress.
